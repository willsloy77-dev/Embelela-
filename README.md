Embelela

Plataforma de Karaoke

O Embelela é uma plataforma de karaoke que permite pesquisar músicas, reproduzir faixas e acompanhar as letras sincronizadas com o áudio.

Estrutura do projecto

- "frontend/" — interface da aplicação.
- "backend/" — API desenvolvida com FastAPI.
- "backend/app/api/" — rotas da API.

Tecnologias

- HTML, CSS e JavaScript
- Python e FastAPI
- API do Jamendo

Desenvolvimento

Este projecto encontra-se em fase de desenvolvimento (MVP).
